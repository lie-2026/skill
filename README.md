# SkillSwap — Peer-to-Peer Learning

React + Express + MongoDB starter for browsing student skill listings, requesting tutoring sessions, and sharing ratings. Seed listings let you explore the experience without a database.

Run `npm install`, optionally copy `.env.example` to `.env` and configure MongoDB, then run `npm run dev`. Build with `npm run build` and run with `npm start`.

Session requests and reviews are demo flows. Connect campus identity, messaging, scheduling, and verified session history before using ratings in a production community.
